# SMART ROUTE — Gemini AI Integration

## Overview
Smart Route integrates Google Gemini AI models to provide passengers and fleet managers with context-aware intelligence.

## Features
- **Passenger Trip Assistant**: Answers questions about real-time ETA, bus amenities, boarding point landmarks.
- **Dynamic Delay Dispatches**: Translates GPS traffic bottlenecks into clear, courteous passenger notices.
- **Function Calling**: AI model can trigger schema-validated functions to query seat availability, upcoming stops, and trip schedules.

## Environment Setup
```bash
AI_PROVIDER=gemini
GEMINI_API_KEY=your_gemini_api_key_here
```
